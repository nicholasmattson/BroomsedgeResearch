Part 1: Raw Data Structure

Below is an example table showing my raw understory data structure:

  • Plot ID: Unique ID. “UB” for unburned control plots, “BBB” for burn plots not receiving augmentation, and BBN for burn plots receiving augmentation.

  • Times Burned: Number of times area burned in recorded times. 1x burn for plots burnt only in 2000. 2x for plots burnt both in 2000 and 1977. 0x for control plots.

  • Augmentation: Whether area received post-fire augmentation (true/false condition)

  • Species Code: Unique taxon code for each recorded species/bare substrate

  • Veg Type: Taxon code classified according to vegetation type (Native woody, invasive woody, invasive grass, etc.). No repeats only logs first occurrence of a species type at a point, so for example if both StyTam and DodVis (both native woody) were recorded at point, only one is logged. This makes classifying plots by veg cover type easier. Veg Type with repeats logs all vegetation recorded by type.

Part 2: Converting raw data to cumulative tally

Raw understory files can be fed into a function called “Species Matrix” which tallies the number of times a taxon code was logged on a per-plot basis, then renders a wide-format table with all the tallies.

Show code 
#function instructions
Species_Matrix <-function(data,
                          output = here("Data","WideData","UnderstoryCover_Tally.csv"),
                          plot_col = "Plot_ID",
                          taxon_col = "Taxon_Code"){
  #columns as symbols
  plot_col <- ensym(plot_col)
  taxon_col <- ensym(taxon_col)
  
  #summary generation
  summary_matrix <- data|>
    #filter any missing records
    filter(!is.na(!!taxon_col))|>
    #group by plot and taxon code, then tally
    group_by(!!plot_col,!!taxon_col)|>
    summarise(tally = n(),.groups = "drop")|>
    #pivot data wide
    pivot_wider(names_from = !!taxon_col,
                values_from = tally)
  
  #export dataframe as csv
  write_csv(summary_matrix, output)
  
  message("Species tally matrix successfully saved to: ", output)
  return(summary_matrix)
}

Part 3: Boxplot Comparisons of Species Cover Across Years

Now they can be graphed to see if there are trends with species cover in different augmentation and burn number factors.

Show code 
#boxplots comparing 2010 and 2026
ggplot(Understory_Tally_Long_Combined,
       aes(x = Augment,
           y = Abundance,
           fill = Year)) +
  geom_boxplot(alpha = 0.7, outlier.shape = 16) +
  facet_wrap(~ Species, scales = "free_y",axes = "all") +
  labs(
    title = "Change from 2010-2026 in Percent Cover",
    subtitle = "Species found in at least 5 plots",
    x = "Augmentation",
    y = "Abundance in Plot"
  ) +
  theme_minimal() +
  theme(
    legend.position = "right",
    strip.text = element_text(face = "bold")
  )

Some quick observations:

  • StyTam cover rose across all classes in all years

  • DodVis cover higher in plots that were augmented for both 2010 and 2026, but especially the latter

  • Leaf Litter much higher in 2010 observations, but I suspect this is due to sampler more than changes to ground cover

  • Augmented plots had much more AcaKoa than not augmented plots in 2010. Now they do not.

Part 4: Comparing Cumulative Cover Types Across Years

Most cover stats from the 2010 report condense species cover to three main categories (Exotic, Native, No Veg). In order to compare the two, I will condense my 2026 data so it can compiled in one large dataset. Then I can compare the years 2010 and 2016 across these three main cover metrics.

Show code 
#group existing veg types in raw data into even more simplified groups for comparison
Understory_Data_byCoverType <- UnderstoryData_Raw %>%
  group_by(Plot_ID, Point_ID) %>%
  mutate(
    temp_cat = case_when(
      Veg_Type_Repeats %in% c("Native_Woody", "Native_Herbaceous", "Native_Grass") ~ "Native",
      Veg_Type_Repeats %in% c("Invasive_Woody", "Invasive_Herbaceous", "Invasive_Grass") ~ "Exotic",
      Veg_Type_Repeats == "Bare_Substrate" ~ "No veg",
      TRUE ~ NA_character_
    ),
    # Check for duplicates of the exact veg type
    New_Status = if_else(
      !is.na(temp_cat) & !duplicated(Veg_Type_Repeats), 
      temp_cat, 
      NA_character_
    )
  ) %>%
  select(-temp_cat) %>%
  ungroup()

Initial thoughts:

  • Clear difference between surveyors as far as what was marked “No Veg”. Will have to ask Sierra at HVNP for her thoughts on how “No Veg” was documented in past survey.

  • Higher range for native cover in augmented plots vs. non-augmented in 2010, and similar trend taking place in 2026. I want to dig into this further.

  • Higher recorded exotic cover in control plots in 2026 vs 2010. I wonder if this is actual expansion of invasive cover or if surveyor affects results.
